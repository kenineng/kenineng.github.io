# Docker 镜像瘦身实战：从 1GB 到 50MB 的秘密

**核心痛点**：镜像体积过大不仅占用存储，还会严重拖慢 CI/CD 部署速度。

**瘦身三大法宝**：

1. **选择轻量级基础镜像**：
* 使用 `alpine` 或 `distroless` 作为基础镜像（如 `node:20-alpine`），相比默认镜像可省去数百 MB 系统资源。


2. **利用多阶段构建（Multi-stage Builds）**：
在编译阶段安装依赖和构建源码，最终镜像只复制打包产物（如 Go 的二进制文件或前端 `dist` 目录）。
3. **减少镜像层数与清理缓存**：
* 将多条 `RUN` 指令整合为一条。
* 安装依赖后立即清理缓存（如 `apt-get clean && rm -rf /var/lib/apt/lists/*`）。
